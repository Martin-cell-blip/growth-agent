## 约定
1. 验收标准编号（AC-xxx）与评测用例编号（EV-xxx）**一一对应**，无孤儿
2. Check 层每出现一次漏检，**当日**转为回归用例
3. 涉及主观维度（清晰度/文化适配）以人工标注为准；LLM judge 只做初筛，且定期与人工标注对齐——judge 也是概率系统，不能自证
