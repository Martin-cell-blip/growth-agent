# ADR-001 · Agent 只提案，管道才执行
> 日期 2026-08-28 · 状态：已采纳

## 背景
LLM 是概率系统；本项目的产出（营销邮件、落地页文案）直接对外，事实错误或未授权外发的代价是信任与合规，不是错别字。企业级要求是确定性承诺，与概率输出天然相悖。

## 决策
1. Agent 的全部输出是**结构化提案**（JSON 契约），不直接触达任何外部系统
2. 执行由确定性管道完成：Check 层（纯规则，无 LLM）→ 人工批准 → 外发
3. **权限隔离在架构层**：Agent 进程不持有邮件发送凭据——约束靠拿不到钥匙，不靠提示词
4. 每次提示词/模型变更过 golden 集行为回归，CI 红灯禁止合并
5. 降级阶梯：Agent 不可用 → 模板库 → 人工；业务循环不因模型故障停摆

## 后果
- 收益：外发零事故可被**证明**（审计日志 + 批准记录），而非被宣称；模型可随时更换，契约不变
- 代价：人工批准是吞吐瓶颈——单人场景可接受；多人场景需批量批准界面（当前非目标）
