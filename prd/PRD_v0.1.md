# growth-agent · PRD v0.1
> 状态：**草稿 v0.1**——文中 **[待裁决]** 项逐一闭合后升 v1.0。仓库即真源，需求文档与代码同仓演进。

## 0. 一句话
一个需求文档驱动、带完整评测与工程兜底的增长 Agent 系统，真实经营 EconLens 英文站的海外自助获客漏斗。

## 1. 问题陈述
两个真问题叠在一起：
- **业务问题**：EconLens 已可用（198 项测试 / Pilot 0 通过）但零海外用户。一个无品牌、零预算的教育 SaaS，如何在英语市场把陌生教师推到自助试用？
- **系统问题**：增长内容生产（邮件、落地页、实验设计、周报）重复性高、受限于单人产能。LLM 能提产能，但概率输出与"对外内容零事故"的要求天然相悖。

GrowthOps 同时回答两者：**用 Agent 提产能，用工程保确定性，用真实漏斗验证效果。**

## 2. 用户与场景
- v0.x 唯一用户：本人（增长 owner 兼 PM）。
- 泛化画像（仅作设计参照，不做承诺）：1-3 人出海小团队的增长运营者，预算≈0，缺内容产能与实验纪律。
- 核心场景：**每周一次增长循环** Plan → Draft → Check → 人工批准 → Execute → Measure → Learn。

## 3. 目标 / 非目标
**目标（8 周）**
- G1 业务：英文站漏斗上线，visitor→activated 全链路可测，基线建立
- G2 系统：Agent / Skill / MCP / Memory 四模块逐版本上线，**每个模块的增益有 before/after 数字（消融）**
- G3 纪律：0 次未批准外发；全部对外内容过确定性 Check 层；每次提示词或模型变更过行为回归

**非目标（防散架，明写）**
- 不做通用框架、多租户、商业化——记忆用 mem0 模式、回归用 promptfoo，**不与轮子竞争**
- 不做付费投放（渠道 = 社群贡献 + SEO + LinkedIn）
- 不承诺流量规模；小样本全程如实披露 n
- 不做对话式 UI；Agent 的交互面 = 结构化提案文件 + CLI

## 4. 指标
| 类型 | 指标 | 说明 |
|---|---|---|
| 北极星（业务） | visitor→activated 转化率 | activated = 托管 Demo 内首次完成一次草稿分析（口径唯一真源 = `specs/funnel_spec.md`） |
| 北极星（系统） | Agent 草稿无修改可用率 | 分母 = 草稿数，不依赖站点流量 |
| 护栏（硬） | 未批准外发数 = 0 | 违反即事故复盘 |
| 护栏（硬） | Check 层漏检的事实错误 = 0 | 发现一例，当日转为回归用例 |
| 护栏 | 邮件退订率 < 行业基准 | 基准值 [待查] |

## 5. 产品原则（进 README）
1. **Agent 只提案，管道才执行**——概率被限制在提案环节
2. **需求先行**——每迭代先 REQ 后代码；验收标准编号 ↔ 评测用例编号一一对应
3. **记忆是治理对象**——写入须批准；洞察带来源/置信度/日期三字段
4. **小样本诚实**——不做显著性表演，n 永远公开
5. **失败是资产**——失败实验进台账，规划前必读，防重复提案

## 6. 版本范围（v0.1–v0.5，消融即路线图）
| 版本 | 周 | 新增 | 消融指标 |
|---|---|---|---|
| v0.1 | W1-2 | 人工基线漏斗（无 Agent）→ **REQ-001** | 业务基线 + 人工产出计时（后续提效的分母） |
| v0.2 | W3 | copy-draft skill + 输出契约 + Check 层 | 无修改可用率、单封产出时间 vs 人工 |
| v0.3 | W4 | experiment-design skill + 实验台账 memory | 提案与历史冲突率下降 |
| v0.4 | W5-6 | analytics MCP 数据回路 + cultural-check 加固 | 周报数字引用错误率、文化校验拦截数 |
| v0.5 | W7-8 | memory-informed 规划 + 元实验（Agent 稿 vs 人工稿 A/B） | 真实打开/点击差异（披露 n） |

## 7. 稳定性需求（非功能，此节即"企业级稳定性"的作品化）
- **S1 输出契约**：100% Agent 输出过 JSON schema；失败 → 修复重试 ≤2 → 回落模板库
- **S2 Check 层无 LLM**：术语黑白名单 / 产品声称溯源（product-truth.md）/ CTA 唯一 / 长度 / 垃圾词 / locale 拼写，全规则实现，**校验器永不放宽**
- **S3 权限隔离在架构层**：外发动作必经人工批准；**Agent 进程不持有邮件发送凭据**——不靠提示词约束，靠拿不到钥匙
- **S4 行为回归**：golden 集全量重放，CI 红灯禁止合并
- **S5 降级阶梯**：Agent 不可用 → 模板库 → 人工；增长循环不因模型故障停摆
- **S6 审计与幂等**：全动作日志可回放；重复执行不重复外发

## 9. 风险
| 风险 | 应对 |
|---|---|
| 分发渠道受限（社群反自我推广规则） | 先贡献后引流；SEO + LinkedIn 兜底 |
| 单人产能与时间盒 | 每版本独立收口，v0.2 即产出首批可复现数字 |
| 数字披露纪律 | 对外数字必须可复现、口径成文、样本量公开；未复核的数字不对外 |
| 隐私 | 订阅者 PII 永不入仓；分析仅用脱敏聚合数据（ADR-002） |
